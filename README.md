# MARQÈ website

Website source imported from M.zip. This is a prototype, not a production release.

## Pages

- `index.html`: homepage, Polish and English
- `wyniki.html`: results dashboard
- `polityka-prywatnosci.html`: draft privacy policy

Open `index.html` in a browser to preview. No build or dependencies are required.

## Before launch

- Reconcile desktop and mobile layouts with Figma v6.
- Replace demo video and project image placeholders with approved assets.
- Build real case studies with verified results and reporting periods.
- Correct live-data claims: dashboard values are currently hardcoded.
- Connect the enquiry form to a delivery service; it currently opens mailto.
- Implement appropriate consent handling; current buttons only dismiss the banner.
- Finalize business details and privacy text to reflect actual services used.
- Check accessibility, mobile navigation, links, and form delivery.
